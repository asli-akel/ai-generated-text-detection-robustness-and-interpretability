# Restricted dataset location

No dataset files are stored in this repository.

Request access to MultiSocial from <https://zenodo.org/records/13846152>. Each researcher must obtain their own approval and comply with the dataset conditions, including the prohibition on resharing the files with anyone outside the approved request.

After authorised download, make `multisocial_anonymized.csv` available in the active working directory for Notebook 1. Notebook 1 produces `multisocial_processed.csv`, which is then used by Notebooks 2 and 3.

Both files are intentionally ignored by Git.
