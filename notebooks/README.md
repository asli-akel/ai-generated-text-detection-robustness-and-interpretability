# Notebooks

Run the notebooks in numerical order:

1. `Notebook1_DataExploration.ipynb`
2. `Notebook2_Multilingual_Experiments.ipynb`
3. `Notebook3_LOGO_Experiments.ipynb`

The notebooks retain aggregate saved outputs from the original Google Colab runs. Saved outputs that reproduced individual records from the restricted MultiSocial dataset were removed from this repository copy. Notebook 3 is computationally intensive and a complete run may take approximately 30 hours.
